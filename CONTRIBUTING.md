# Правила внесения изменений

## Обязательно

Перед любым коммитом — `make verify`.

## Запрещено

1. Пропускать тесты (`@pytest.mark.skip`, `xfail`) без обоснования в комментарии.
2. Снижать порог покрытия ниже 40% в `pytest.ini`.
3. Добавлять `# noqa` без указания причины.
4. Коммитить с флагом `--no-verify`.

## Исключения

Любое исключение должно быть обосновано в комментарии рядом и одобрено на code review.
